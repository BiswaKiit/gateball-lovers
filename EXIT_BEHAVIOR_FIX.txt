Gateball Lovers - Exit Confirmation Removed

The custom "Do you want to Exit? Yes / No" behavior has been removed.

The app now uses normal browser/PWA navigation. A member can use the
device/browser Home or app controls to leave Gateball Lovers, and can reopen it
later. The persistent sign-in/session behavior remains unchanged.

No Supabase authentication, signup/email verification, profile, tournament,
or chat database changes are included in this patch.

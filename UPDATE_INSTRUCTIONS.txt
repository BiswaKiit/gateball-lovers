Gateball Lovers - Notification Prompt Restored / Exit Removed

This package restores the Dashboard "ALLOW CHAT NOTIFICATIONS" prompt for
members whose browser notification permission is still default or not chosen.

The custom Yes/No Exit dialog and its history guard are completely removed.
Normal browser/PWA navigation is used.

Existing login, signup, email verification, persistent session, profile,
tournament and chat functionality are not intentionally changed.

IMPORTANT:
The Dashboard notification permission/subscription UI is present, but true
closed-app Web Push delivery still requires VAPID server credentials and
subscription persistence/sending to be configured. The current Flask endpoint
returns the public key and accepts the subscription but does not yet send
server-side push messages.
